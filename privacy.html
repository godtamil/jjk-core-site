Privacy Policy

This policy describes data processed by JJK CORE when installed in a Discord server. The features used depend on each server’s configuration.

Data used by the bot

The bot uses Discord user, server, channel, and role identifiers to run commands and apply permissions. Depending on enabled features, it may store server settings, activity and XP records, moderation records, verification status, ticket information, and DM alert preferences.

Messages and music

The bot may process messages for moderation, leveling, tickets, and mention or reply alerts. Alerts can contain the sender, server, channel, time, and a link to the original message. Use /dm-alerts enabled:false in a server to turn these alerts off there. Music searches and track links are sent to the configured Lavalink service.

Access and retention

Server staff may see records or logs available to them under the server’s settings and permissions. Stored records are subject to the server configuration and the operator’s hosting and backup settings. Discord and the bot’s hosting and playback services process information needed to provide their services.

Data questions and requests

For questions or requests concerning your data, ask the administrators of the relevant Discord server to put you in touch with the JJK CORE operator. Include the server and feature involved so the relevant record can be located.
